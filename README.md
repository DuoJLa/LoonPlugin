# LoonPlugin

Loon plugins converted from Egern and other proxy formats.

## Included

- `NodeSeek.plugin` — NodeSeek Cookie capture and scheduled daily check-in.
- `NodeSeek-Loon.js` — Loon-compatible script used by the plugin.

## NodeSeek usage

1. Add `NodeSeek.plugin` to Loon.
2. Enable **Cookie捕获** in the plugin arguments.
3. Open your NodeSeek personal page once.
4. After receiving the Cookie success notification, disable **Cookie捕获**.
5. Configure the check-in hour/minute and optionally enable **固定鸡腿**.

The original Egern source is attributed to [Nullwhy/Egern](https://github.com/Nullwhy/Egern).
